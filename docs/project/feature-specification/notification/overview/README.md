# Overview

> **Status:** Stable
>
> **Last Updated:** 2026-09-12

This area establishes the framing for everything else: why Notifications exists, what falls
inside and outside its responsibility, and the vocabulary the rest of the specification assumes.

It contains **no rules**. Behavior is stated in [`preferences/`](../preferences/README.md),
[`relevance/`](../relevance/README.md), [`intents/`](../intents/README.md) and
[`history/`](../history/README.md), and ruled on in [`decisions/`](../decisions/README.md).
