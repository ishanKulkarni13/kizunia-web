## Why the story register lives here

The user stories were written before the behavioral decisions were finalized, and several of them
describe capabilities that are now future scope or explicit non-goals. Keeping the complete
register with an explicit status column means:

- nothing from the design sessions is silently lost;
- nobody re-proposes a capability that was deliberately declined;
- the boundary between "not yet" and "not ever" stays visible.

Where a story is not Phase 1, the register says where it went.
